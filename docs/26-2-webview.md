# WebView 앱 보완

디버그 빌드는 격리 홈 개발 주소, 릴리스 빌드는 기존 운영 주소를 엽니다. 쿠키 공유/저장과 UpbrellaApp 사용자 에이전트를 설정하고 카메라 권한 요청·사진 선택 사용 설명을 추가합니다. 허용한 HTTPS 호스트만 앱 내부에서 열며 외부 링크는 시스템 앱으로 넘깁니다. 혼합 콘텐츠는 허용하지 않습니다. Android/iOS 아이콘과 Android 시작 화면을 새 로고로 맞춥니다.

TypeScript, 기존 렌더 테스트, plist/XML과 아이콘 참조를 검사했습니다. 카메라 권한 거절/재허용, 사진 선택, 카카오·Apple 복귀 및 앱 재시작 로그인 유지는 실제 iOS·Android 기기 확인이 필요합니다. 스토어에 배포하지 않습니다.
